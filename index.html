    시연 도구

    이 앱에 일부러 넣은 불편 요소
    1. 스플래시 3.5초, 건너뛰기 없음
    2. 자동 로그인 없음 — 앱을 켤 때마다 로그인
    3. 로그인·회원가입 뒤 고른 시설을 잊고 홈으로 이동
    4. 회원가입 12개 항목, 오류는 제출 시 하나씩만 팝업
    5. 비밀번호: 10자+영문·숫자+특수문자 2개, 숨은 규칙(연속 숫자 금지) 있음
    6. 오류가 날 때마다 비밀번호 칸 초기화
    7. 가입 때 입력한 휴대폰 번호를 본인인증에서 다시 입력
    8. 가입 완료 후 다시 로그인
    9. 예약 화면에서 시설을 다시 선택 (홈에서 고른 시설 무시)
    10. 달력이 화면보다 넓어 금·토요일과 ▶ 버튼이 잘림
    11. 지난 날짜도 고를 수 있고, 저장해야 오류 표시
    12. 점검 시간(12시)도 체크됨 → 저장 시 시간 선택 전부 초기화
    13. 글자 크기 12px 고정, 확대 불가
    14. 결제는 가상계좌만, 24시간 미입금 시 자동 취소(알림 없음)
    15. 입금 전인데도 "예약이 완료되었습니다" 표시
    16. 변경·취소는 전화로만 — 앱에 취소 버튼 없음
